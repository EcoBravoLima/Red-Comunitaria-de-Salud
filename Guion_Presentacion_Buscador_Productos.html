4. Botón Limpiar: Al dar clic en 'Limpiar', se borra el texto, se devuelve el foco al input y reaparecen las 20 divisiones completas.

Minuto 2:50 a 4:15 • Explicación del Archivo JavaScript (buscador.js)

"(Mostrando public/js/buscador.js en el editor)
El archivo buscador.js está estructurado en 4 partes limpias y explícitas:

1. Enlace ById: Con document.getElementById capturamos el input de texto, el botón de limpiar y los indicadores visuales.

2. Enlace ClassName: Con document.getElementsByClassName('producto') capturamos la colección viva de las 20 divisiones de productos.

3. Funciones explícitas para cada acción:
• mostrarDivision(division): Restablece division.style.display = '' y retira la clase CSS hidden.
• ocultarDivision(division): Asigna division.style.display = 'none' y agrega la clase CSS hidden.
• buscarProductos(): Lee el texto en minúsculas, recorre las divisiones y mediante indexOf verifica si coincide con las clases de la división (donde pusimos el nombre del producto y categoría) o con su contenido de texto. Si coincide la muestra; si no, la oculta.
• limpiarBusqueda() y actualizarContador().

4. Eventos con addEventListener: Desacoplamos totalmente el JS del marcado HTML escuchando los eventos input y keyup sobre la caja de texto, y el evento click sobre el botón de limpiar."

4. Banco de Respuestas a Preguntas del Profesor

¿Por qué usar getElementsByClassName en lugar de querySelectorAll? Porque getElementsByClassName devuelve un HTMLCollection en vivo con excelente rendimiento y atiende con precisión el requerimiento pedagógico de la materia para manipular colecciones por clase.
¿Qué ventaja tiene escuchar el evento input frente a keyup? keyup solo reacciona cuando se suelta una tecla física; input se dispara con cualquier modificación del valor, como pegar texto con el clic derecho o borrar con el teclado virtual. Usamos ambos para garantizar cobertura total.
¿Cómo se garantiza que funcione la búsqueda por clases de productos? Con division.className.toLowerCase() obtenemos la cadena completa de clases (ej. 'articulo producto vacunacion prod-influenza'), y con indexOf(textoBusqueda) !== -1 validamos si el término buscado forma parte de las clases del producto o de su categoría.
